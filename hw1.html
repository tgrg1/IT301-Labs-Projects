Homework 1

For the assignment homework 1, we learned how to create and update files using Git and GitHub with pull requests.

I also learned the definitions for the following terms:

  • Repository (Repo): The database where your project is stored with its complete history
  • Clone: Copy a remote (online) repository to your local machine
  • Branch: A version of the repository kept separate from all of the others that can be used to test new features and the like
  • Commit: Each individual uploaded change to a file or files that let you keep track of the history of changes made over time and by whom
  • Push: Uploading local commits to a remote repository
  • Pull: Downloading remote commits to a local repository
  • Pull Request: A feature of GitHub that allows users to propose changes which can be accepted or rejected by the repository's authors
  • Merge: Taking two branches and applying the changes from one branch into the other
